# Next.js Auth0 JWT Projesi

Bu proje, Next.js (App Router) kullanılarak geliştirilmiş bir kimlik doğrulama ve yetkilendirme sistemidir. Auth0 ile OAuth 2.0 tabanlı kullanıcı girişi sağlanır ve NextAuth.js üzerinden JWT tabanlı oturum yönetimi gerçekleştirilir.

## 🚀 Özellikler

- Auth0 ile OAuth 2.0 kimlik doğrulama
- NextAuth.js ile Auth0 entegrasyonu
- JWT tabanlı oturum doğrulama
- Middleware ile korumalı sayfalar
- SOLID prensiplerine uygun modüler yapı
- 12-Factor App prensiplerine uygun yapılandırma
- TailwindCSS ile tasarlanmış Login sayfası
- TypeScript desteği
- Geliştirme ve üretim branch yapısı (`dev/v1.0.0`, `prod/v1.0.0`)

## 🛠️ Kullanılan Teknolojiler

- Next.js 14+ (App Router)
- Auth0
- NextAuth.js
- JWT
- TailwindCSS
- TypeScript
- dotenv
- Git / GitHub

## 📁 Branch Stratejisi

- `dev/v1.0.0`: Tüm geliştirmeler bu branch üzerinde yapılır.
- `prod/v1.0.0`: Kararlı sürüm kodları bu branch’te tutulur.
